# 🧾 Split It

[![CI](https://github.com/Facundo1/cost-splitter/actions/workflows/ci.yml/badge.svg)](https://github.com/Facundo1/cost-splitter/actions/workflows/ci.yml)

Split group expenses (a dinner, a trip, a shared flat) and find out **who pays whom, with the fewest transfers**.

**Live demo:** https://Facundo1.github.io/cost-splitter/

Add people → add expenses (who paid, who it's split between) → see what each person spent and the transfers that settle everyone → share the summary to a WhatsApp chat or group. Data stays in your browser — no account, no server.

## Quick start

Requires Node 20+ (`.nvmrc` pins 24).

```bash
npm install
npm run dev        # http://localhost:5173
```

| Script              | What it does                                  |
| ------------------- | --------------------------------------------- |
| `npm run dev`       | Dev server with HMR                           |
| `npm test`          | Unit + component tests (Vitest, jsdom)        |
| `npm run test:watch`| Tests in watch mode                           |
| `npm run lint`      | ESLint                                        |
| `npm run typecheck` | `tsc --noEmit` (strict)                       |
| `npm run check`     | Lint + typecheck + context check + test — same as CI |
| `npm run context`   | Regenerate the AI source index (`.ai/INDEX.md`) |
| `npm run build`     | Production build to `dist/`                   |
| `npm run preview`   | Serve the production build locally           |

## How it works

```
src/
├── lib/                 # Pure domain logic — no React, fully unit-tested
│   ├── types.ts         # Person, Expense, Payment, Transfer
│   ├── money.ts         # Parse/format integer cents, display conversion
│   ├── currency.ts      # USD, ARS, EUR
│   ├── ledger.ts        # Group state + pure operations
│   ├── settle.ts        # Shares, balances, greedy settlement
│   ├── share.ts         # WhatsApp summary + wa.me link
│   └── backup.ts        # Save / open a JSON copy of the group
├── rates/               # ExchangeRateReader. Axios is the HTTP adapter
├── components/          # Welcome screen, panels, save/open
├── store/
│   └── ledgerStore.ts   # Zustand store (persisted); actions delegate to lib/ledger
└── App.tsx              # Welcome gate + three-column workspace
```

1. **Balances.** Each bill adds its amount to the person who paid and subtracts a share from each person on it. Equal shares are the default. Parts (2 means twice as much) are optional. Leftover cents are assigned deterministically so balances always sum to exactly zero.
2. **Settlement.** Repeatedly match the person who owes the most with the person who is owed the most. At most *n − 1* payments. The true minimum is NP-hard; greedy is optimal or very close for a normal group. "Mark as paid" records a payment and the list shrinks.
3. **One currency.** The group picks USD, ARS, or EUR. Switching it renames the amounts; it does not convert bills already added. "Also show in" is a live rate, rounded to the cent, and it is not used to settle.

All money is stored as **integer cents** — no floating-point rounding bugs.

## Working on this repo with AI

The repo ships layered context so AI assistants (Claude Code, Codex, Cursor…) get the right context without reading the whole codebase:

| Layer | File | Loaded |
| --- | --- | --- |
| Router | [`AGENTS.md`](AGENTS.md) (+ `CLAUDE.md` → `@AGENTS.md`) | Every prompt — kept short |
| Area guides | [`src/lib/AGENTS.md`](src/lib/AGENTS.md), [`src/components/AGENTS.md`](src/components/AGENTS.md) | Only when working in that folder |
| Symbol map | [`.ai/INDEX.md`](.ai/INDEX.md) | On demand, to find the right file before opening it |

`.ai/INDEX.md` is generated by [`scripts/context-map.mjs`](scripts/context-map.mjs) and **CI fails if it's stale**, so the context can't silently drift from the code.

## CI/CD

[`.github/workflows/ci.yml`](.github/workflows/ci.yml) runs on every push and PR: lint → typecheck → context check → test → build. On `main`, the build is deployed to GitHub Pages.

> To enable deploys on a fork: *Settings → Pages → Source: GitHub Actions*.
